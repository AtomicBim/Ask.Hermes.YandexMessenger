# ГРАНД-Смета — извлечение и сопоставление смет

Работа со сметной документацией: выгрузки ГРАНД-Смета (Excel-ЛСР и печатные PDF), извлечение позиций, сравнение редакций (исходная ПД ↔ РД по изменениям), построение СВОР (сопоставительная ведомость объёмов работ).

## When to Use

- Разобрать смету/ЛСР (ГРАНД-Смета) из xlsx или PDF — извлечь позиции, объёмы, обоснования.
- Сравнить две редакции (исходная ПД ↔ РД) по листам изменений (`.1`, `.2 доп.`).
- Построить СВОР по образцу в Excel.
- Для прочих (несметных) Excel/PDF — скиллы `microsoft-office` и `pdf`.

## Виды файлов
- **ЛСР / смета** — локальный сметный расчёт. Выгрузка бывает в xlsx (Excel) и в PDF (печатная форма).
- Один PDF почти всегда содержит **несколько смет**: базовую (`ЛС-…-Изм.1`) и листы изменений (`.1` = изменение, `.2 доп.` = дополнение).
- **СВОР** — сопоставительная ведомость, сравнивает «объём по ПД (положит. заключение ГЭ)» против «объём по РД» с колонками +увеличение / −снижение.

## xlsx-выгрузка (структура и ловушка индексов)
- Заголовок использует объединённые ячейки, поэтому **не бери колонки по фиксированному индексу** — ищи подписи по первым строкам. Реальный расклад ГРАНД: «№ п/п»=A, «Обоснование»=B, «Наименование работ и затрат»=C, но «Единица измерения»=**H(8)**, «Количество»=**I(9)** — не D/E.
- Верхнеуровневые позиции имеют число в «№ п/п». Ресурсные подстроки — пустой № или коды-ресурсы: `91.01.05-086` (машина), `1-100-25` (маш.-ч), `4-100-060` (ОТм), `Пр/812-…` (НР), `Пр/774-…` (СП), `02-15-1-01-0080` (перевозка). Оставляй только строки с числовым № п/п.

## PDF (парсинг перемешанного текста)
- Раздели сметы по маркеру `ЛОКАЛЬНЫЙ СМЕТНЫЙ РАСЧЕТ (СМЕТА) № (\S+)` (re.finditer → границы листов).
- Текст `pymupdf.get_text()` сильно перемешан (колонки вперемешку): сначала `re.sub(r"\s+"," ", …)`, потом регэксп.
- Единицы — **упорядоченный список, длинные раньше**, иначе `м3` схватится внутри `1000 м3`: `1000 м3|100 м3|100 м2|10 м3|10 м2|10 шт|маш.-ч|чел.-ч|кВт-ч|м3|м2|шт|кг|км|м\b|т\b`.
- Количество = **первое** число после единицы (`-?\d+(?:[.,]\d+)?`). Не захватывай «последовательности чисел через пробел» — так в объём попадают стоимости («40 1 40 44,86» → сцепится).
- Ресурсные подстроки: обоснования ФСБЦ/ФСЭМ c `_` (напр. `…-0426_02-15-1-01-0030`) — транспортные ресурсы, пропускать. У `ТЦ_…` знак `_` — часть легитимного кода, не пропускать.

## ПД vs РД / изменения (главная ловушка интерпретации)
- `Изм.1` = смета с **уже применённым** изменением 1; `.1` и `.2 доп.` — дельта-листы к ней.
- **Проверяй, учтена ли дельта**, до того как строить сравнение: если значение позиции N в `.1` совпадает со значением той же расценки в `Изм.1`, дельта уже внутри → исходная ПД = `Изм.1` − дельта (а не «Изм.1 — это ПД»).
- Коды обоснований **не уникальны**: один материал/расценка встречается в нескольких позициях (напр. «Песок» = и сам песок, и «перевозка песка»). Сопоставляй дельты к базе **по номеру позиции**, не по коду.
- Для сверки сумм используй сметную стоимость листа (надёжнее, чем суммы натурных объёмов, у которых разные единицы).

## СВОР — формат
Столбцы образца: «№ п/п | номер ЛСР | номер позиции | наименование работ | ед.изм | объём по ПД (ГЭ) | объём по РД | изменение (+увеличение / −снижение) | обоснование изменений». Разделы («Раздел 1…») отдельными строками-заголовками, позиции группируются по разделам.
Столбец «номер позиции» = номер в `Изм.1` (число); дельты `.2 доп.` бывают двумя способами: отдельными строками «Добавлено по РД» (номер в Изм.1 пустой, а в «номер позиции в доп. смете» стоит `N (доп.)`) ИЛИ прибавкой к объёму существующей позиции (тогда `РД − ПД` = дельта). Отсюда полный список дельт `.2 доп.` (отдельный лист/файл) длиннее, чем счёт строк «Добавлено по РД» — модификации существующих позиций там не отдельные строки.

## Сравнение двух файлов СВОР
- **Сначала выясни базу «ПД» каждого файла** — они могут различаться, и это главный источник ложных «расхождений». Один файл может брать «ПД» = `Изм.1` (изменение 1 уже учтено), другой — «ПД» = исходная ПД (до изм.1). Признак согласованности: `F1.ПД ≈ F2.РД` (обе = Изм.1), `F2.ПД = F1.ПД + дельта .1`, `F1.РД = F2.РД + дельта .2 доп.`. Если это сходится — файлы согласованы, а не противоречат друг другу.
- Сопоставляй позиции **по номеру в Изм.1** (не по коду обоснования — он не уникален).
- Разница объёмов в 4–5-м знаке (`1.89897` vs `1.899`) — это округление (разная точность в файлах), классифицируй как «ОК», не как расхождение. Порог «реального» расхождения — когда разница на порядок крупнее, не в последних цифрах.
- Позиции «возврат материалов» (трубы/изделия к поз. демонтажа) могут присутствовать только в одном файле — это отдельный признак неполноты, выноси в отчёт отдельно.
- Сверяй итоги по **сметной стоимости** листа (тыс.руб.), а не по суммам натурных объёмов с разными единицами.
