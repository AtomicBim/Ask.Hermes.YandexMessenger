# Project folder structure on the corporate Disk

Access to the Disk itself (WebDAV, credentials, pitfalls) is described in the shared `yandex-disk` skill; this skill only
records the folder convention used for project material.

Work is organised as `/ПРОЕКТЫ/<проект>/<номер>. <категория>/`, e.g. `0. Продуктовая концепция`, `1. ЭП`, `2. Дизайн МОП`,
`3. Дизайн благоустройства`, `7. Бренд-концепция`. Deliver material into the matching numbered folder (create a named
subfolder for the element, e.g. `Лифты`).
